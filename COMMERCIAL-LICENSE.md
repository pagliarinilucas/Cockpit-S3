# Cockpit S3 — Licenciamento

O Cockpit S3 é distribuído sob **licença dupla (dual licensing)**. Você escolhe
uma das duas opções abaixo.

## 1. Licença open source — GNU AGPL v3

O código-fonte é livre sob a
[GNU Affero General Public License v3.0 ou posterior](./LICENSE) (`AGPL-3.0-or-later`).

Em resumo, sob a AGPL você **pode** usar, estudar, modificar e redistribuir o
software gratuitamente, inclusive hospedá-lo para uso próprio, **desde que**:

- Todo trabalho derivado seja também licenciado sob AGPL v3.
- **Cláusula de rede (§13):** se você **oferecer o software como serviço**
  (acesso pela rede a usuários), precisa disponibilizar a esses usuários o
  **código-fonte completo e correspondente** da versão em execução, incluindo
  suas modificações.

Se esses termos servem para você, não precisa fazer mais nada — use sob a AGPL.

## 2. Licença comercial

A AGPL é inadequada para muitas empresas: departamentos jurídicos frequentemente
proíbem AGPL, e a §13 obriga a abrir o código de qualquer modificação oferecida
como serviço. Se você quer:

- **Embutir** o Cockpit S3 (ou parte dele) em um produto proprietário;
- **Oferecê-lo como serviço** (SaaS) **sem** abrir suas modificações;
- Redistribuí-lo sob termos que a AGPL não permite;
- Obter garantias, suporte ou indenização contratual,

então você precisa de uma **licença comercial**, que dispensa as obrigações de
copyleft da AGPL.

O detentor dos direitos autorais oferece essa licença comercial separadamente.

## Por que dual licensing funciona

Todo o código deste repositório tem copyright de **Lucas Pagliarini**, único
titular dos direitos. Isso permite oferecer o mesmo código sob dois conjuntos de
termos: a comunidade usa gratuitamente sob AGPL; quem não pode aceitar o copyleft
compra a licença comercial.

## Contribuições

Ao contribuir com este projeto (pull requests, patches), você concorda que sua
contribuição seja licenciada sob AGPL-3.0-or-later **e** cede ao detentor do
copyright o direito de relicenciá-la sob os termos da licença comercial. Sem essa
cessão a contribuição não pode ser incorporada, pois quebraria o modelo de dual
licensing. Um CLA (Contributor License Agreement) formal será exigido antes do
merge de contribuições de terceiros.
