// why now

The free S3 consoles got smaller.

May 2025

MinIO trims the CE console

The Community Edition console was reduced to an object browser. User, policy and admin screens moved out of the free UI.

Feb 2026

MinIO archives the community repo

The open-source repository was archived. Teams running MinIO CE are looking for a maintained console — or a new backend.

Today

Garage is great storage

Its own web UI is a simple admin panel: buckets, keys, objects. It isn't built to hand files to dozens of people safely.

Cockpit S3 sits on top of whichever S3 backend you choose — keep MinIO, move to Garage, or use a hosted provider — and gives every team the same users, permissions, links and audit trail.

// the problem

Buckets are cheap. Handing them to people is not.

The link nobody remembers

A contract shared by public link eight months ago. Still live. Who can open it today? Nobody can tell you.

Access keys passed around

Everyone gets the same key, or you hand-write IAM policies per person. Neither scales, and neither is something finance can use.

"Who touched this file?"

No record of who uploaded, downloaded or deleted. When the auditor asks, the answer is an awkward silence.

  • No proprietary format — objects stay plain S3 (or encrypted, if you choose)

// security & compliance

Serious security, without the weight

Engineering honesty is the style: if it's listed here, it's enforced on the server. No theatre, no jargon.

Encryption at rest

Each file is encrypted on the server with its own key before it reaches storage. The bucket only holds scrambled blobs with random names — a leaked backup, disk or credential reveals nothing.

Backup & disaster recovery

Automatic, encrypted backup of keys and the metadata index to a destination you choose. Lose the console machine, restore everything — your files never left your storage.

Data residency

Data on your infrastructure, under your jurisdiction. Nothing crosses a border unless you send it.

Encryption in transit

TLS end to end between browser, console and object storage.

Built-in audit log

A timeline of uploads, downloads, deletions and of who granted or revoked access.

Token architecture

argon2id passwords, short-lived tokens with instant revocation, rotating refresh with theft detection and login rate limiting.

// faq

Honest questions, straight answers

Is Community really free with unlimited users?

Yes. The Community edition is AGPL-3.0 and includes the full core: permission matrix, folder overrides, expiring links, previews, spreadsheet editor, audit log, Garage admin, encryption at rest and DR backup. No user limits, no time limits.

Then why would I pay for Pro?

Three reasons: a commercial license if your legal team doesn't want AGPL obligations (for example, when you modify the code and expose it to users), SSO and compliance features (OIDC, audit export to your SIEM, retention), and a support channel with a response time. It also funds the project.

Can it replace the MinIO Console?

For the day-to-day — browsing, uploading, sharing, users and permissions — yes. Point Cockpit at your MinIO endpoint and keep running MinIO, or move the data to Garage or a hosted provider later; the console stays the same. Enterprise includes hands-on migration help.

Which storage providers work?

Any S3-compatible endpoint: Garage, MinIO, Hetzner Object Storage, Backblaze B2, Wasabi, AWS S3, Oracle OCI and others. You can manage several connections at once from the UI.

Do I need to know S3 to use it?

Your admin connects the storage once. After that it's drag, drop, set permissions and share. S3 stays behind the scenes.

Are files encrypted?

They can be. Turn on encryption at rest per bucket and each file is encrypted on the server with its own key before it is written — storage only sees unreadable blobs with random names. For people with access in the console, preview and download work as usual.

What about backups?

Your files live in your object storage, not in a proprietary silo. Cockpit also runs automatic, encrypted backups of the encryption keys and metadata index to a destination you choose — if the console machine is lost, you restore access in minutes.

How does the expiring link work?

Someone with share permission creates a public link to a file — no login for the recipient. Pick a lifetime from 1 hour to 30 days and optionally lock it to the first IP that opens it. Revoke anytime. A view-only user can never create a download link.

What counts as a production instance?

One running deployment that real users work in. Staging, test and development instances don't need a license.

Is it hard to operate?

One container, embedded SQLite, no external dependencies. It starts in minutes on any server with Docker.
