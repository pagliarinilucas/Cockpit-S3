## Configuration reference

| Variable | Default | Purpose |
| --- | --- | --- |
| `ACCESS_TOKEN_SECRET` | — | **Required in production**, 32+ characters. Signs access tokens. |
| `ACCESS_TOKEN_TTL` | `900` | Access token lifetime in seconds. |
| `REFRESH_TOKEN_TTL` | `2592000` | Refresh token lifetime in seconds. |
| `COOKIE_SECURE` | `true` in production | Send the refresh cookie only over HTTPS. Set `false` only for plain HTTP on localhost. |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | `admin` / random | Initial admin, created only when no user exists. A blank password is generated and printed in the log. |
| `PORT` | `3000` | HTTP port. |
| `DB_PATH` | `/data/cockpit.sqlite` in the image | SQLite database. |
| `PUBLIC_URL` | derived from proxy headers | Public origin, used for the OIDC redirect URI. |
| `COCKPIT_KEK_FILE` / `COCKPIT_KEK` | — | Key-encryption key (32 bytes, raw or base64) for encryption at rest. |
| `COCKPIT_LICENSE_FILE` / `COCKPIT_LICENSE_KEY` | — | Pro/Enterprise license key. |
| `LOGIN_MAX_ATTEMPTS` / `LOGIN_WINDOW_MS` | `8` / `300000` | Login rate limit. |
| `ZIP_MAX_ENTRIES` | `20000` | Maximum files in one ZIP download. |
| `UPLOAD_SPOOL_THRESHOLD` / `UPLOAD_SPOOL_DIR` | 2 GiB / system temp | Encrypted uploads larger than the threshold are spooled to disk. |
| `MERGE_PDF_MAX_TOTAL_BYTES` | 2 GiB | Limit for the PDF merge action. |
| `CORS_ORIGIN` | `http://localhost:4200` | Only when the web app is served from another origin. |

S3 connections are configured in the UI, not in environment variables. `S3_ENDPOINT`, `S3_REGION`, `S3_ACCESS_KEY`, `S3_SECRET_KEY` and `BUCKETS` are only read to seed the first connection on an empty database.
